# تزگور | TezGor

صفحه‌ی معرفی ربات `@TezGorBot` برای رصد مزایدات و مناقصات سامانه ستاد ایران.

## ساختار
- `index.html`: صفحه اصلی
- `style.css`: استایل و طراحی واکنش‌گرا
- `app.js`: انیمیشن ورود عناصر و رفتارهای تعاملی
- `images/bot-preview.webp`: تصویر معرفی ربات
- `images/inspection.webp`: تصویر بخش بررسی دقیق

برای انتشار در GitHub Pages، فایل `DEPLOY.md` را بخوانید.
